# Tapreel

Your photos → cinematic reel in one tap.

Pick a photo, pick a look (Cinema / Vivid / Soft Film / Night Neon), get an instant 6s 9:16 reel with punch-in/pan cuts and color grade. Share to TikTok or Reels.

Inspired by the “AI Reel in one tap” idea — not affiliated with Vids.app.

## Run locally

```bash
python3 -m http.server 8770
```

Open `http://localhost:8770` on iPhone Safari (same network) or desktop.

## Screens

- `#home` — Make AI Reel
- `#library` — photo grid
- `#style` — look chips + Make reel
- `#play` — 9:16 player + scrubber
- `#share` — TikTok / Reels / Save
